## About

AI engineer building practical applications with large language models, retrieval-augmented generation and agentic workflows. Currently pursuing a B.Sc. in Computer Science at BITS Pilani.

## Currently building

**[GitCommit AI](https://github.com/vaibhav-barman/gitcommit-ai)** (`git ai-commit`): an agentic, repository-aware commit assistant. It learns how a repository writes commits, drafts a message in that style, and runs it past a deterministic critic loop before you see it. Supports OpenAI, Anthropic, Gemini and local Ollama models.
